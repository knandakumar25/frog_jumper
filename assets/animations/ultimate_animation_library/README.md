# Tomazod / Ultimate Animation Library — Free Demo

20 selected animations, white mannequin, GLB 2.0, root motion and in-place variants.
Includes the first 10 clips, every ad highlight, saber slash, low lunge (tackle), leg-catch throw and power ball kick.

Open Godot_Project/project.godot in Godot 4.7 or newer and press F6/F5.
Left/right: browse all 20. Space: pause/resume. Home: automatic showcase.
R: switch between root motion and in-place GLBs at runtime.
The default scene uses root motion. To preview in-place, add --in-place to the
project's main-run arguments, or switch the source in showcase.gd to white_in_place.glb.
No paid animation clips or control bones are included in these GLBs.
Props are not included; holding and weapon animations provide the character choreography.
