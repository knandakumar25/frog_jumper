# Localization wording guide

Keep existing CSV operative and civilian name translations. Registry display names,
mission numbers, cue IDs, action IDs and save/API fields are identities and remain
unchanged. AXIOM FORCE and AXIOM-7 may retain their brand spelling; subtitle speaker
transliterations need consistency review before linguistic acceptance.

| English concept | Usage |
| --- | --- |
| Data-Blade | The recovered history archive, not an ordinary combat weapon. New Spanish `Hoja de Datos`, French `Lame de données`, Portuguese `Lâmina de Dados`, German `Datenklinge`, Italian `Lama Dati`, Polish `Ostrze Danych`, Turkish `Veri Kılıcı`, Indonesian `Pedang Data`, Vietnamese `Lưỡi Kiếm Dữ Liệu`. Match the authored Tokyo/card terminology; native review remains pending. |
| Kinetic Parry | Shogun's timed projectile deflection; do not imply passive armor. |
| Tidal Torrent / douse | Oceanus extinguishes/neutralizes heat; keep separate from shield regeneration. |
| Tectonic Slam | Titan's rubble-breaking signature action. |
| Harmonic Pulse / resonate | Aura's sonic-lock action. |
| Phase Blink | Mirage's protected traversal through a hazard, not an ordinary dash. |
| Solar Bulwark | Surya's protected heat/fire crossing. |
| identity originals | Authentic civic records recovered in Mission 5; exclusion is an access policy, not deleting the player's save. |
| extraction / recovery | Mission completion versus checkpoint return; keep these distinct. |

Preserve named/numeric placeholders, BBCode, newlines and physical button symbols.
Avoid forcing translated text to uppercase. The authored English source and
existing English recordings remain authoritative for meaning and timing.
